## Key Takeaways

- RootMe is a beginner-friendly CTF room that connects web security and Linux security concepts.
- Reconnaissance gives direction before deeper testing.
- Enumeration is more important than guessing.
- Web applications may expose hidden directories or interesting functionality.
- Hidden directories are not automatically secure.
- File upload functionality must be protected carefully.
- Getting a shell conceptually shows the impact of weak web security.
- Linux enumeration helps understand users, permissions, files, and system context.
- Privilege escalation often happens because of misconfiguration or weak permissions.
- Least privilege reduces the impact of compromise.
- Cybersecurity practice must always be ethical and authorized.

## Defensive Learning

- Organizations should reduce unnecessary exposed services.
- Web applications should protect sensitive directories.
- File upload features should validate file type, content, size, storage location, and permissions.
- Uploaded files should not be executable by default.
- Applications should enforce server-side validation and authorization.
- Linux permissions should be reviewed regularly.
- Systems should follow the principle of least privilege.
- Logs should be monitored for suspicious uploads, web requests, command execution, and privilege-related activity.
- Security testing should always support defensive improvement.
