## Key Takeaways

- CTFs help build practical cybersecurity thinking.
- Reconnaissance is the foundation of security testing.
- Enumeration is more important than guessing.
- Web applications can expose useful information.
- Vulnerability research helps connect findings with known risks.
- CVE awareness is important for security learners.
- Weak authentication creates serious security risk.
- Linux enumeration helps understand system permissions.
- Privilege escalation often depends on misconfiguration.
- Least privilege reduces the impact of compromise.
- Offensive learning should always support defensive improvement.
- Cybersecurity practice must always be ethical and authorized.

## Defensive Learning

- Organizations should reduce unnecessary exposed services.
- Services should be patched, monitored, and securely configured.
- Web applications should avoid exposing sensitive information.
- Hidden resources should still require proper access control.
- Authentication systems should enforce strong password policies.
- Linux permissions should be reviewed regularly.
- Systems should follow the principle of least privilege.
- Logs should be monitored for scanning, suspicious login attempts, and privilege-related activity.
- Vulnerability research helps defenders prioritize patching and remediation.
- CTF learning improves understanding of real-world attack paths and defensive controls.
