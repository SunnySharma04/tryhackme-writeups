## Key Takeaways

- Network security is a core part of cybersecurity.
- Networks must be understood before they can be defended.
- Visibility is essential for detection and investigation.
- Logs provide evidence for security analysis.
- Firewalls help control and record network traffic.
- IDS and IPS tools help detect suspicious activity.
- VPN access should be monitored carefully.
- The network perimeter is often the first area attackers interact with.
- Port scanning may indicate reconnaissance.
- Repeated login attempts may indicate brute-force activity.
- Regular outbound traffic may indicate malware beaconing.
- SOC analysts must connect multiple pieces of evidence before making conclusions.
- Defensive security depends on monitoring, analysis, response, and documentation.

## Defensive Learning

- Organizations should monitor perimeter traffic continuously.
- Exposed services should be reviewed and reduced where possible.
- Firewalls should be configured carefully and reviewed regularly.
- IDS/IPS alerts should be investigated with context.
- VPN logs should be monitored for suspicious login behavior.
- Security teams should understand normal network traffic baselines.
- Repeated connection attempts should be investigated.
- Brute-force patterns should be detected and escalated.
- Malware beaconing patterns should be monitored.
- Host-centric and network-centric logs should be correlated.
- SOC analysts should document findings clearly and accurately.
