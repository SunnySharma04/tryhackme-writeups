## Key Takeaways

- Passive reconnaissance collects information without directly interacting with the target system.
- Active reconnaissance directly interacts with the target and should only be done with authorization.
- WHOIS helps gather domain registration information.
- DNS records can reveal useful infrastructure details.
- nslookup and dig are useful tools for querying DNS records.
- DNSDumpster helps discover DNS records and subdomains.
- Shodan shows publicly exposed internet-facing services.
- Public information can reveal important details about an organization.
- Reconnaissance should always be performed ethically and responsibly.
- Passive reconnaissance is useful for penetration testing, SOC analysis, threat intelligence, and vulnerability management.

## Defensive Learning

- Organizations should regularly review their public exposure.
- WHOIS information should be accurate and managed properly.
- DNS records should be reviewed for unnecessary exposure.
- Old or unused subdomains should be removed.
- Publicly exposed services should be monitored.
- Shodan can help defenders identify exposed internet-facing assets.
- DNS and domain information can support phishing and threat intelligence investigations.
- Passive reconnaissance helps defenders understand what attackers may see publicly.
- External attack surface monitoring is important for reducing risk.
