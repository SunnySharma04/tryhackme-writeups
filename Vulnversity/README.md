## Key Takeaways

- Penetration testing follows a structured methodology.
- Reconnaissance helps understand the target environment.
- Service enumeration identifies exposed services.
- Directory discovery helps find hidden web paths.
- Hidden directories are not automatically secure.
- Web servers must be configured safely.
- File upload features must be validated and restricted.
- Initial access shows the risk of weak web controls.
- Privilege escalation highlights the danger of weak permissions.
- Least privilege helps reduce the impact of compromise.
- Offensive security knowledge should always lead to defensive learning.

## Defensive Learning

- Organizations should reduce unnecessary exposed services.
- Web servers should be securely configured.
- Hidden directories should not be treated as security controls.
- Sensitive paths should require authentication and authorization.
- File uploads should be restricted and validated properly.
- Uploaded files should not be executable by default.
- User and file permissions should be reviewed regularly.
- Systems should be patched and hardened.
- Logs should be monitored for scanning, directory discovery, suspicious uploads, and privilege escalation attempts.
- Least privilege should be applied to users, services, and application accounts.
