## Key Takeaways

- A computer system includes both hardware and software.
- The CPU processes instructions and performs calculations.
- RAM stores temporary active data while the system is running.
- Storage saves files and data for long-term use.
- SSDs are generally faster than HDDs.
- The motherboard connects different computer components.
- BIOS or UEFI helps start the system before the operating system loads.
- The power supply provides electricity to internal components.
- Peripherals allow users to provide input and receive output.
- Computer fundamentals are important for cybersecurity, troubleshooting, digital forensics, SOC work, and system security.

## Defensive Learning

- Understanding hardware helps defenders investigate endpoint issues.
- High CPU usage may indicate suspicious processes or system problems.
- RAM can contain useful evidence during memory analysis.
- Storage devices may contain logs, malware samples, deleted files, or forensic evidence.
- Unknown USB devices and peripherals can create security risks.
- Firmware and boot settings can affect system security.
- Strong computer fundamentals help cybersecurity learners understand tools, logs, malware behavior, and system activity more clearly.
