## Key Takeaways

- Networking is a core foundation of cybersecurity.
- The OSI model explains network communication in seven layers.
- Encapsulation adds layer-specific information as data moves through the network stack.
- Decapsulation happens when the receiving system removes layer information.
- The TCP/IP model explains practical internet communication.
- Ping helps check basic host reachability.
- Traceroute helps understand the path traffic takes.
- WHOIS provides domain registration information.
- Dig helps query DNS records.
- Networking knowledge supports both offensive and defensive cybersecurity roles.

## Defensive Learning

- Defenders need networking knowledge to investigate suspicious traffic.
- OSI and TCP/IP models help structure troubleshooting.
- Ping can help test basic connectivity.
- Traceroute can help identify network path issues.
- WHOIS can support suspicious domain investigation.
- Dig can help analyze DNS records.
- DNS and network traffic are important in SOC investigations.
- Strong networking fundamentals improve log analysis, incident response, and security monitoring.
